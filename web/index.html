Archives and checkpoints stay in this application’s folder. They are not encrypted. Anyone with access to these files can read them.

What an archive includes

Messages your account can access within the chosen dates. Threads and forum posts can be included. Downloaded files have per-file and total size limits.

Deleted messages, ephemeral responses and voice recordings cannot be recovered. Permissions can hide history; an empty response does not prove a channel was empty.

Each job fixes its end time when started. Resuming continues that snapshot. Start a new export to collect newer messages or edits.

Markdown and HTML include readable message details. JSON preserves the full message objects, including fields not shown in the reader.
