Keep a copy of your server's channels.

Pick channels, choose a date range, and save them as Markdown, HTML, JSON, CSV or text. Everything is written to a folder on this computer and stays searchable here.

Setting up the bot

  1. Create an application in the Developer Portal and add a bot to it.
  2. On the Bot page, turn on Message Content Intent and copy the token.
  3. Invite the bot to your server with View Channels and Read Message History.

Exports and the database are plain files in the app folder. They are not encrypted, so anyone who can open the folder can read them.

What an export contains

  • Messages the bot can read in the chosen channels and dates.
  • Threads and forum posts, when that option is on.
  • Attachment links, and the files themselves if you turn on downloads.
  • The end of the range is fixed when the export starts. Run a new export to pick up later messages or edits.
  • Deleted messages, ephemeral replies and voice audio cannot be exported.
  • An empty channel can also mean the bot is missing Read Message History.

Session

The token stays in memory. Disconnecting pauses running exports and clears it. Closing the browser tab does not stop the app.
